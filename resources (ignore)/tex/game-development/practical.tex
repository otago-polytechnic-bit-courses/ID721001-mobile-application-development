\section*{Assessment Overview}
In this \textbf{individual} assessment, you will provide two short reports that will support you in the development of your mobile applications for the \textbf{Project} assessment.

\section*{Learning Outcomes}
At the successful completion of this course, learners will be able to:
\begin{enumerate}
  \item Implement and publish complete, non-trivial, industry-standard mobile applications following sound architectural and code-quality standards.
  \item Identify relevant use cases for a mobile computing scenario and incorporate them into an effective user experience design.
  \item Follow industry standard software engineering practice in the design of mobile applications.
\end{enumerate}

\section*{Authenticity}
All parts of your submitted assessment \textbf{must} be completely your work. The use of \textbf{AI tools} is not permitted in this assessment. You need to demonstrate to the course lecturer that you can meet the learning outcomes for this assessment. You \textbf{must} complete the \href{https://moodle.op.ac.nz/mod/page/view.php?id=1178172}{Academic Integrity Declaration} form and put this in the root of your repository. \section*{Instructions}

\textbf{Note:} Please read the \textbf{Project} instructions before starting this assessment. 

\subsection*{System Design - Learning Outcomes 1, 2 (10\%)}
\begin{itemize}
  \item Write a short report (500-1000 words) covering the system design for each game (v1 and v2), including:
  \begin{itemize}
    \item Game architecture and main components.
    \item How data is managed.
    \item Key design choices regarding scalability, maintainability and performance.
  \end{itemize}
\end{itemize}

\subsection*{UI Design - Learning Outcomes 1, 2 (10\%)}
\begin{itemize}
  \item Write a short report (500-1000 words) covering the UI design for each game (v1 and v2), including:
  \begin{itemize}
    \item Responsive design for different screen sizes and orientations.
    \item UI/UX decisions, including navigation, interactions and usability.
    \item Wireframes or mockups for key screens showing layout and navigation.
  \end{itemize}
\end{itemize}

Please submit the reports as either \textbf{.pdf} or \textbf{.docx} files in the root of your repository.
