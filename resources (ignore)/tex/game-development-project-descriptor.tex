\section*{Instructions}

\subsection*{Functionality - Learning Outcomes 1, 2 (20\%)}
\begin{itemize}
  \item Game v1 where the user interacts using basic gestures.
  \item Game v2 with \textbf{ten features} of your choice (this can build on v1).
  \item Create an \textbf{APK} for both v1 and v2.
\end{itemize}   

\subsection*{Code Quality and Best Practices - Learning Outcomes 1, 3 (35\%)}
\begin{itemize} 
\item Write clean, readable, and maintainable code.
\item Use modular, reusable components and avoid code duplication.
\item Keep code simple and easy to understand.
\item Ensure the games are responsive across different screen sizes and orientations.
\item Optimise performance by managing resources efficiently.
\end{itemize}  
 
\subsection*{Version Control - Learning Outcome 3 (5\%)}
\begin{itemize}
  \item Regular commits are made throughout development, demonstrating meaningful progress.
  \item Commit messages are clear and descriptive.
  \item The repository shows a clean and logical commit history that reflects the development process of the games.
\end{itemize}

\subsection*{Testing - Learning Outcome 3 (10\%)}
\begin{itemize}
  \item Test the games with three different users for each version (six users total), observing how they navigate and use features.
  \item Collect written feedback on usability issues, confusing UI and bugs.
  \item Write a brief report summarising the user testing, including:
  \begin{itemize}
    \item Tester information (anonymised).
    \item Tasks performed.
    \item Positive feedback received.
    \item Areas for improvement identified.
    \item Bugs or errors found.
    \item Suggestions on how feedback could be used to improve the games (no requirement to implement).
  \end{itemize}
\end{itemize}

\subsection*{Reflection - Learning Outcomes 1, 3 (5\%)}
\begin{itemize}
  \item Write a short reflection (300-500 words) on your development process and learning throughout the project, including:
  \begin{itemize}
    \item Challenges you faced and how you overcame them.
    \item What you would do differently in future projects.
    \item New skills, tools or practices you learned during the project.
  \end{itemize}
\end{itemize}

\subsection*{Presentation - Learning Outcome 2 (5\%)}
\begin{itemize}
  \item Record a 5-10 minute screen recording of your games.
  \item Demonstrate the v1 and v2 features.
  \item Make sure the video is clear and easy to follow.
  \item Submit a link to the presentation in your repository's \textbf{README.md} file.
\end{itemize}
